# Hướng dẫn cài đặt

FastAPI bước đầu, schema, seed và kiểm thử có thể chạy theo [hướng dẫn backend cho PowerShell](../../backend/README.md). Chưa có lệnh chạy web/mobile; khi triển khai, bổ sung phiên bản Node.js, Expo, cấu hình môi trường và lệnh chạy từng thành phần.

Không đưa mật khẩu, token hoặc dữ liệu thật vào tài liệu hay mã nguồn. Khi có cấu hình thực tế, tạo tệp `.env.example` chỉ chứa giá trị mẫu an toàn.
