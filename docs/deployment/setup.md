# Hướng dẫn cài đặt

Chưa có ứng dụng hoặc lệnh cài đặt đã được kiểm chứng. Khi triển khai, bổ sung phiên bản Python, Node.js, Expo, cấu hình môi trường, cách khởi tạo SQLite và lệnh chạy từng thành phần.

Không đưa mật khẩu, token hoặc dữ liệu thật vào tài liệu hay mã nguồn. Khi có cấu hình thực tế, tạo tệp `.env.example` chỉ chứa giá trị mẫu an toàn.
