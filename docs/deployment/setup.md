# Hướng dẫn cài đặt

Chưa có ứng dụng hoặc lệnh chạy ứng dụng. Schema SQLite có thể được khởi tạo theo [hướng dẫn backend](../../backend/README.md). Khi triển khai ứng dụng, bổ sung phiên bản Python, Node.js, Expo, cấu hình môi trường và lệnh chạy từng thành phần.

Không đưa mật khẩu, token hoặc dữ liệu thật vào tài liệu hay mã nguồn. Khi có cấu hình thực tế, tạo tệp `.env.example` chỉ chứa giá trị mẫu an toàn.
