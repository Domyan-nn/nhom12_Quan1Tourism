# Kịch bản demo

Kịch bản dự kiến: khách tìm và xem địa điểm, xem bản đồ, chọn ngôn ngữ và nghe TTS; thử GPS tự phát trên mobile; Admin đăng nhập, quản lý và công bố nội dung; khách chọn quyền thống kê và Admin xem kết quả.

Trước buổi demo cần ghi phiên bản, thiết bị, kết nối, dữ liệu mẫu và cách tạo tài khoản Admin. Các bước cụ thể sẽ được bổ sung sau khi hệ thống chạy được.
